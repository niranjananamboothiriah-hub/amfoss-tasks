# Task 00: Install Linux

## Objective:


The objective of this task was to install a Linux operating system and become familiar with using Linux as the primary environment for the upcoming amFOSS tasks.

## What I Did

I installed **Ubuntu Linux** alongside Windows using a dual-boot setup. This allows me to choose between Windows and Ubuntu whenever I start my laptop.

Before installing Ubuntu, I backed up my important data and prepared the disk space required for the installation.

### Installation Steps

1. Downloaded the Ubuntu ISO image.
2. Created a bootable USB drive containing Ubuntu.
3. Booted the laptop from the USB drive.
4. Started the Ubuntu installation process.
5. Selected the required keyboard and language settings.
6. Configured the installation and disk partitions.
7. Installed Ubuntu alongside Windows.
8. Completed the installation and restarted the laptop.
9. Verified that both Windows and Ubuntu were available through the boot menu.
10. Successfully booted into Ubuntu and tested the system.

## Linux Environment

After installation, I opened the Ubuntu terminal and started getting familiar with basic Linux commands and the Linux filesystem.

Some basic commands I practiced were:


* pwd
* ls
* cd
* mkdir
* touch
* cp
* mv
* rm

These commands helped me understand navigation, file management, and working with directories in Linux.
